\# 🥗 MacroSnap



MacroSnap is an AI-powered nutrition buddy built with Streamlit and Gemini.



It allows users to ask questions about food and nutrition, upload meal photos, estimate calories and macronutrients, and generate a short nutrition summary.



\## ✨ Features



\- 👤 Simple user onboarding

\- 💬 AI nutrition chat

\- 📸 Meal photo analysis

\- 🔥 Calorie estimation

\- 💪 Protein estimation

\- 🍚 Carbohydrate estimation

\- 🥑 Fat estimation

\- 📋 Nutrition conversation summary

\- 📱 WhatsApp integration using Twilio



\## 🛠️ Technologies Used



\- Python

\- Streamlit

\- Google Gemini

\- Google GenAI SDK

\- Twilio WhatsApp
